# 上海电机学院毕业设计（论文）LaTeX 模板

上海电机学院本科毕业设计的 LaTeX 模板：**学士学位论文**、**开题报告**、**任务书**、**中期检查报告**和**指导记录**，依据学校下发的模板制作。

| 目录 | 内容 | 依据 |
|---|---|---|
| [`thesis/`](thesis/) | 学士学位论文模板及示例 | 《教学归档材料及质量评价要素（2026 版）》附件25《学士学位论文封面》、附件26《毕业设计（论文）格式规范》；学校《形式审核关键点内容（26 年 5 月及之后答辩的插入 AI 使用情况声明页）》 |
| [`proposal/`](proposal/) | 开题报告模板及示例 | 同上，附件23《毕业设计（论文）开题报告》；同一份形式审核要点 |
| [`taskbook/`](taskbook/) | 任务书模板及示例 | 《教学归档材料及质量评价要素（2026 版）》附件22《毕业设计（论文）任务书》 |
| [`midterm/`](midterm/) | 中期检查报告模板及示例 | 同上，附件24《毕业设计（论文）中期检查报告》 |
| [`logbook/`](logbook/) | 指导记录模板及示例 | 同上，附件32《毕业设计（论文）指导记录》 |
| [`word-templates/`](word-templates/) | 学校下发的 Word 原始模板 | — |

各模板目录各自独立、互不依赖，每个模板只有一个类文件，复制其中一个目录就可以开始写。示例的排版效果见 [`thesis/main.pdf`](thesis/main.pdf)、[`proposal/proposal.pdf`](proposal/proposal.pdf)、[`taskbook/taskbook.pdf`](taskbook/taskbook.pdf)、[`midterm/midterm.pdf`](midterm/midterm.pdf) 和 [`logbook/logbook.pdf`](logbook/logbook.pdf)。

## 编译

```bash
cd thesis   && latexmk main.tex       # 论文：xelatex -> biber -> xelatex -> xelatex
cd proposal && latexmk proposal.tex   # 开题报告
cd taskbook && latexmk taskbook.tex   # 任务书（midterm、logbook 同理）
latexmk -c                            # 清理中间文件
```

需要 TeX Live 2020 及以上（含 ctex、biblatex-gb7714-2015、biber）。

## 字体

规范要求宋体、黑体、Times New Roman，封面用微软雅黑。模板自动检测：有 Windows 字体就用，没有则用 TeX Live 自带的 Fandol（中文）和 TeX Gyre Termes（西文）代替，版式不变。

在 WSL 中使用 Windows 字体：新建 `~/.config/fontconfig/fonts.conf`

```xml
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "fonts.dtd">
<fontconfig><dir>/mnt/c/Windows/Fonts</dir></fontconfig>
```

然后运行 `fc-cache -f`。

## 论文的格式规定（thesis/sdjuthesis.cls）

行距按 Word 的文档网格换算：单倍 = 15.6 磅，1.25 倍 = 19.5 磅，2 倍 = 31.2 磅。

标题、目录等处的间距按 Word 的「行框」算法换算（实现见 `sdjuthesis.cls` 的 `\sdju@pre`、`\sdju@post`）：

- 每行占一个行框，行框高即行距；四号、小二号字高于一格网格，单倍行距时占两格（31.2 磅）。
- 文字在行框内上下居中，段前、段后加在行框之外。
- 相邻两段的段后与段前取较大者，不叠加（如一级标题后紧跟二级标题、二级标题后紧跟三级标题）。

因此下表各处只需给出「字号、行框高、段前、段后」，改格式时改这几个参数即可。

| 部分 | 格式 |
|---|---|
| 页面 | A4；上 2.8 cm，下、左、右 2.5 cm；页眉 2 cm |
| 页眉 | 左：论文题目，黑体小五号；右：页码，小五号；下有 0.75 磅横线；无页脚 |
| 封面 | 附件25：校徽；「学士学位论文」40 磅微软雅黑；中文题目、英文题目（`\titleen`）小一号微软雅黑，行距 46.8 磅；栏目三号宋体，依次为学生姓名、学生学号、专业、校内指导教师、企业指导教师、学院，栏目名按实际宽度、下划线右端对齐，行距 31.2 磅；日期在栏目下两行。各处位置按 2026 版 PDF 量取。题目超过两行时，多出的高度一半由题目及以上部分上移、一半由栏目下移 |
| 页码 | 封面无页眉页脚；声明、摘要、目录 I, II, …；正文起 1, 2, …（页眉右侧，即右上角） |
| 声明页 | 学术诚信声明、AI 使用情况声明、版权使用授权书各一页。附件26 样本只有第一、三页；**AI 使用情况声明页是学校样本之外按用户要求保留的**（学校《形式审核关键点内容》也列出「26 年 5 月及之后答辩的插入 AI 使用情况声明页」），不需要时用 `noaideclaration` 选项去掉。签名、日期留空手写；授权书的「保密 / 不保密」默认留空手工勾选，也可用 `\confidential{年数}` 或 `\notconfidential` 印出勾选。全页 2 倍行距（31.2 磅）：空两行，标题两行（「上海电机学院」+ 声明名称）小二号黑体加粗居中，空一行，正文四号宋体、首行缩进 2 字符；签名前空三行（AI 使用情况声明内容多，空一行），签名与日期之间空一行 |
| 摘要 | 标题小二号黑体居中；正文小四号宋体，首行缩进 2 字符，1.25 倍行距，段前段后 12 磅（与标题的段后 12 磅不叠加）；「关键词：」五号黑体，关键词小四号 |
| ABSTRACT | 标题小二号 Times New Roman 加粗居中，段前 31.2 磅；正文同上；「Key words:」五号加粗 |
| 目录 | 标题小二号黑体加粗居中，段前 31.2 磅、段后 12 磅；一级标题黑体四号（行框 31.2 磅），二级标题黑体小四号（行框 15.6 磅）并缩进 2 字符，均为单倍行距；引导线为短横线；页码统一五号 |
| 一级标题 | 小二号黑体加粗居中，行框 31.2 磅，段前 0、段后 12 磅，每章另起页，编号「1 绪论」；摘要、参考文献、致谢等标题同此格式 |
| 二级标题 | 四号宋体，首行缩进 2 字符，行框 31.2 磅，段前 12、段后 0 磅，编号「1.1」 |
| 三级标题 | 小四号黑体，首行缩进 2 字符，行框 15.6 磅，段前 12、段后 0 磅，编号「1.1.1」 |
| 正文 | 小四号宋体 / Times New Roman，首行缩进 2 字符，1.25 倍行距 |
| 断行 | 与 Word 一致，英文单词不用连字符拆开；网址、长标识符可在 `/ . - _` 等符号处换行 |
| 分项 | (1)、(2)、(3)…，与正文同样缩进 |
| 公式 | 另起一行居中，按章编号「（2-1）」，编号右对齐 |
| 表 | 三线表，线粗 0.5 磅；表名在表正上方，宋体小五号加粗「表2-1 …」；表内文字小四号、单倍行距（列多时可用 `\sdjutablesize` 改小）；一页放得下的表用 `table` + `tabular`，跨页的长表用 `longtable`，续页右上方「续表2-1」并重复表头 |
| 图 | 图名在图正下方，宋体小五号加粗「图2-1 …」 |
| 参考文献 | GB/T 7714-2005 顺序编码制（与样本一致）；正文中 `\cite` 为上标「[1]」；条目小四号，悬挂缩进 2 字符，1.25 倍行距；可由 `.bib` 生成，也可在 `references` 环境中手工录入 |
| 致谢 | 标题小二号黑体居中；正文五号宋体，首行缩进 2 字符，单倍行距 |
| 附录（可选） | 放在致谢之后，`\appendix` 之后的 `\chapter` 编为「附录A」…，进目录，图表公式编为 A-1 … |

## 常用命令

```latex
\documentclass[noaideclaration]{sdjuthesis}  % 可选：去掉 AI 使用情况声明页；nodeclaration 去掉全部声明页
\title[页眉短题目]{封面题目，可用 \\ 换行}  \titleen{English Title}   % 英文题目只印在封面
\author{} \studentid{} \school{} \major{}
\supervisor{}            % 校内指导教师
\companysupervisor{}     % 企业指导教师（可不写，封面该栏留空；旧文档只写 \supervisor 也能编译）
\coverdate{二〇二七年五月}
\confidential{3}  或  \notconfidential   % 可选：授权书中印出勾选，默认留空手工勾选

\makecover                 % 封面
\frontmatter \makedeclaration
\keywords{甲，乙，丙}  \begin{abstract} ... \end{abstract}
\keywordsen{A, B, C}   \begin{abstracten} ... \end{abstracten}
\sdjutableofcontents
\mainmatter  \chapter{} \section{} \subsection{}
\backmatter  \sdjubibliography
\begin{acknowledgements} ... \end{acknowledgements}
\appendix  \chapter{程序清单}   % 可选：附录A

\cite{key}          % 上标引用 [1]
\parencite{key}     % 非上标 [1]
\sdjucontinued{4}   % longtable 续页表头中的「续表x-x」（参数为列数）
\sdjutablesize{10.5bp}  % 其后表格的表内文字改用五号（放在花括号里只对一个表有效）
\sdjuspacing{1.5}   % 按 Word 的倍数设置当前行距
```

### 手工录入参考文献

没有 `.bib` 文献库（例如从 Word 稿转过来）时，用 `references` 环境代替 `\sdjubibliography`，标题与条目格式相同，条目自动编号：

```latex
正文中引用\sdjucite{1}，或多篇\sdjucite{2-4}。   % 上标 [1]、[2-4]

\begin{references}
  \item 蒋有绪, 郭泉水, 马娟, 等. 中国森林群落分类及其群落学特征[M]. 北京: 科学出版社, 1998: 11-12.
  \item\label{ref:ahn} Ahn H, Kim K J, Han I, et al. Hybrid genetic algorithms …[J]. Expert Systems, 2010, 23(3): 127-144.
\end{references}
```

条目加了 `\label` 后，可写 `\sdjucite{\ref{ref:ahn}}`，调整条目顺序时编号自动跟着变。

### 表格注意事项

- `longtable` 不是浮动体。它和 `[t]`、`[htbp]` 的图表落在同一页时，版心可能被撑破（内容超出下边距）。所以一页放得下的表一律用 `table` + `tabular`；确实要跨页的长表才用 `longtable`，必要时在它前面加 `\clearpage`。
- 列数多的表在小四号下排不开时，用 `{\sdjutablesize{10.5bp} \begin{table} … \end{table}}` 把这一个表改成五号。

## 开题报告（proposal/sdjuproposal.cls）

依据《教学归档材料及质量评价要素（2026 版）》附件23《毕业设计（论文）开题报告》（PDF 样本，位置按它量取）和学校《形式审核关键点内容》。附件23 中没有图表，也没有规定图表的格式，模板在这方面采用与学位论文格式规范（附件26）相同的做法：三线表，表名在上、图名在下，宋体小五号加粗。

附件23 的 Word 文件没有启用文档网格，行框的算法与论文不同：单倍行距的行框高为 1.3 × 字号，「x 倍行距」多出的部分全部加在文字下方（文字在行框上部）。模板的 `\sdju@above`、`\sdju@below` 按这一算法换算，已与 2026 版 PDF 中标题、正文、参考文献的基线位置核对（误差 0.5 磅以内）。

| 部分 | 格式 |
|---|---|
| 页面 | A4；上 2.54 cm，下 2 cm，左、右 2.5 cm；页脚距纸边 1.25 cm，页码小五号，**默认在页脚右侧**（2026 版附件23 样本）；可用 `\documentclass[pagenumcenter]{sdjuproposal}` 改为居中；封面无页眉页脚 |
| 封面 | 边框内自上而下逐行排，均为 1.5 倍行距：段前 18 磅，校名与「毕业设计（论文）开题报告」一号华文中宋加粗（行高按样本中华文中宋的实际行高计）；空两行；栏目依次为课题名称（两行下划线）、学院、专业、班级、学号、姓名、**校内指导教师、企业指导教师**，小二号宋体加粗，内容（小三号）写在下划线上，下划线右端对齐；空两行；定稿日期小三号加粗。课题名称一行写不下时自动转到第二行（两行约 34 个汉字，再长则自动缩小字号，也可用 `\\` 手工分行） |
| 课题名称 | 小一号宋体加粗居中；副标题以「——」开头右对齐 |
| 摘要、关键词 | 「摘要：」「关键词：」小四号加粗，内容小四号宋体，首行缩进 2 字符 |
| 一级标题 | 四号宋体加粗，左对齐，1.73 倍行距（行框 31.55 磅），段前段后 13 磅（「1 文献综述」） |
| 二级标题 | 小四号宋体，首行缩进 2 字符（「3.1 …」） |
| 正文 | 小四号宋体 / Times New Roman，首行缩进 2 字符，1.25 倍行距 |
| 进度安排 | `schedule` 环境，内容换行后与首行内容对齐 |
| 参考文献 | 另起一页，「参考文献：」小二号黑体加粗居中，1.5 倍行距；条目小四号单倍行距，**不缩进**（编号顶格，转行也顶格，与附件23 一致）；同样可用 `references` 环境手工录入 |
| 意见页 | `\supervisoropinion{...}` 指导教师意见、`\committeeopinion` 答辩小组意见与结论，各占一页，留签名和日期位置；表格宽度、行高、栏目名位置按附件23 量取。答辩小组页在附件23 中单独成节（左右边距 3.17 cm、上下 2.54 cm），模板在这一页同样换用该页面设置 |

```latex
\title{课题名称} \subtitle{副标题} \school{} \major{} \classname{} \studentid{} \author{}
\supervisor{} \companysupervisor{}   % 校内、企业指导教师（企业可不写，该栏留空）
\finaldate{2027 年 1 月 10 日}  \keywords{甲，乙，丙}
\makecover  \maketitle  \begin{abstract} ... \end{abstract}
\section{文献综述} ...  \begin{schedule} \item{时间段}{工作内容} \end{schedule}
\sdjubibliography  \supervisoropinion{}  \committeeopinion
```

## 任务书、中期检查报告、指导记录

三套表格类模板依据《教学归档材料及质量评价要素（2026 版）》中的附件22、24、32（该文件只有 PDF；2026 版中「学生工作及教师指导记录本」已改为一页表格的「毕业设计（论文）指导记录」）。页面均为 A4，上下 2.54 cm、左右 3.17 cm，不印页码；表格的宽度、伸出版心的位置、行高按 2026 版 PDF 量取。表格内填写的文字为小四号宋体、1.25 倍行距、首行缩进 2 字符。

表格中的大栏目（任务书的四个栏目、中期报告、指导教师意见）可以跨页：内容少时按原表的行高留白，写不下时在页底断开、下一页接着排；签名栏总在栏目底部。栏目内可用 `\subsection`（小四号加粗，编号 1、2…）、`enumerate`、`schedule`。

**任务书（taskbook/sdjutaskbook.cls）**：封面方框内为校名（小初号华文中宋，无则宋体加粗）、「毕业设计（论文）任务书」（一号），各栏目小三号、行距 40 磅：课题（两行，过长自动缩小字号）、专业、班级、姓名、学号、学院院长（签字）、校内指导教师（签字）、企业指导教师（签字）、日期；框外「注」。反面为竖排栏目名（四号仿宋）的四栏表格。

```latex
\title{课题} \major{} \classname{} \author{} \studentid{}
\school{} \supervisor{} \companysupervisor{}   % 封面上没有这几栏或须手签，只作记录
\taskdate{20XX 年 XX 月 XX 日}
\makecover
\section{课题来源} ... \section{课题的目的、意义} ... \section{要求} ...
\section{课题主要内容及进度} ... \begin{schedule} \item{时间段}{工作内容} \end{schedule}
\section[60mm]{要求}   % 可选参数改栏目最小高度
```

## 与学校样本（WPS 输出）的已知差异

模板按统一参数排版，不逐像素模仿 WPS。下列差异属于排版引擎不同或样本本身的不一致：

- **折行位置**：TeX 按整段优化断行，WPS 逐行排满并会压缩标点，个别行末的字会落在不同行。
- **声明页页码**：2026 版样本两页声明编为 I、II，摘要 III；模板多一页 AI 使用情况声明，依次为 I～III，摘要从 IV 起。
- **目录**：样本目录是手工输入的（含正文中没有的「1.4 本章小结」）；模板根据正文标题自动生成。
- **章编号**：样本正文中「结论」为第 5 章（中间章节省略），目录里却写「3 结论」；模板按实际顺序自动编号。
- **参考文献**：由 GB/T 7714-2005 样式生成，与样本手工文字略有出入（如「北京: 」后有空格，英文作者缩写不加点）。
- **空白与位置**：样本中原红色批注处留有空白，图表位置随之不同；模板中的图表按浮动体自动放置。
- **声明页**：2026 版样本两页声明的标题高度一致，与模板的「空两行」相同（基线误差 0.1 磅）；签名栏的左右位置按半页宽对齐，不照搬样本里用空格凑出的位置。
- **表格**：三线表的线与文字之间用 booktabs 的默认间距，比样本略松；样本表格撑满版心，模板按内容宽度居中。
- **页眉页码**：样本的页码右侧留了约 3 个字符的空，模板的页码贴齐右边距。
- **论文封面**：日期中的「〇」用汉字零（U+3007），附件25 样本里是几何圆圈「○」（U+25CB）。题目超过两行时样本没有规定，模板按上面「封面」一行的规则移动。
- **论文表格**：学校《形式审核关键点内容》中「表的格式及标注」截图是全框线表格，但附件26 的 2026 版样本仍是三线表，模板保持三线表。
- **开题报告页码**：去年的形式审核要点文字要求「底部居中」，与 2026 版附件23 样本（页脚右侧）冲突，以 2026 版为准，模板默认右侧；`pagenumcenter` 选项可改为居中。
- **形式审核要点与 2026 版的关系**：形式审核要点是 2025 年的版本，两者冲突时一律以 2026 版为准（例如论文表格仍用三线表）。
- **开题报告意见页**：签名后的「年 月 日」样本中用空格凑出的间距不一（1.5～2.5 字），模板统一为 2 字；答辩小组页各项位置、表格尺寸按样本。
- **开题报告**：封面、正文各处与 2026 版附件23 PDF 的基线位置相差在 1.5 磅以内。封面的华文中宋字体需自行安装（没有时用宋体代替，位置不变）。
- **任务书、中期检查报告、指导记录**：依据 2026 版 PDF 量取的参数排版，不逐点照搬。封面各行按 40 磅等距排（样本中「课题」一行比等距位置高约 2.5 磅）；竖排栏目名统一字距 22 磅（样本各栏 18～25 磅不等），顿号「、」居中（样本靠右）；样本中的「指导教师意见:」为半角冒号，模板用全角「：」；表格内填写文字的格式（小四号宋体、1.25 倍行距）是模板的约定，样本表格是空的，没有规定；没有方正大标宋、华文中宋时分别用宋体加粗代替。

- 各模板各依据各的原件，类文件互相独立。字体检测、断行、表格行（`\sdju@row`、`\sdju@formrow`）等写法相同的部分在几个类文件里各有一份，修改这些部分时要逐个看一下。
- 模板按统一的格式参数排版，不逐像素模仿 Word 的输出；与样本的差异见上一节。
